# 프로젝트 목표와 제약

## 만들고 싶은 것

십이장기에서 출발해, 플레이어가 기물과 능력을 선택하고 조합하며 한 런을 진행하는 웹 로그라이크를 탐색한다. 폰 브라우저에서 주소 하나로 실행하고, 일본의 동료에게도 바로 보여줄 수 있어야 한다.

이 저장소는 단일 기획을 확정해 밀어붙이는 곳이 아니라 십이장기 기반 로그라이크 변형을 비교·폐기할 실험실이다. 실험용이라는 이유로 인게임에 미완성 메뉴나 개발 기획서를 노출하지 않는다. 제공하는 플레이 흐름은 그 자체로 완결되어야 한다.

## 최종적으로 확인할 경험

- AI 상대와 혼자 한 판을 끝까지 플레이할 수 있다.
- 전투 → 보상 선택 → 다음 전투가 이어지고, 선택한 기물이 이후 운영을 바꾼다.
- 융합/진화를 통해 두 요소의 결합에서 새로운 작동 방식이 생긴다. 정해진 조합식인지, 몸체·능력 조합인지, 장비 효과 조합인지는 아직 확정하지 않았다.
- 언어·화면 크기가 플레이를 방해하지 않고, 현재 말이 무엇을 할 수 있는지 읽힌다.
- 재미없는 변형을 버리고 기준판으로 돌아갈 수 있다.

위 경험은 방향이다. 런 길이, 콘텐츠 수, 최종 규칙이나 상용 출시 일정은 약속하지 않았다.

## 확정된 개발 제약과 선호

- 구현과 이미지 제작은 AI 활용을 전제로 한다. 사용자는 목적·선택·플레이 피드백·병합 판단을 담당한다.
- 프레임별 스프라이트 애니메이션 제작 부담을 피한다. 정적 이미지와 코드 기반 이동·강조·전환 효과는 사용 가능하다.
- 이미지는 NovelAI, 로컬 SD 계열, 사용 가능한 이미지 생성 도구 등을 후보로 둔다. 아직 특정 도구나 아트 스타일을 고정하지 않았다.
- 현재 기술은 Vite + TypeScript + CSS이며 GitHub Pages에서 실행한다. 최종 플랫폼까지 불변으로 확정한 것은 아니다. 변경에는 현재 구조가 막는 구체적인 이유가 필요하다.
- 인게임은 한국어·일본어·영어를 지원한다. 개발 문서는 한국어 중심으로 작성해도 된다.
- 스테이지 실험에서는 플레이어가 소수 기물로 시작하고 극초반 적은 그보다 더 적은 기물로 시작한다. 상대를 항상 풀기물로 채우지 않는다. 초기 수와 배치는 미정이다.
- 융합/진화는 반드시 탐색하고 싶은 핵심 관심사다. 다만 당장 첫 구현 순위는 AI 상대와 런의 최소 흐름보다 뒤다.

## 참고 아이디어의 지위

역전 오셀로니아의 보드+캐릭터 카드 구조, 백팩 배틀즈의 합체, 하데스의 융합 은혜, 오토체스의 동일 유닛 합성/시너지, PokéRogue의 유전자쐐기는 비교 아이디어다. 특정 게임의 규칙·이미지·캐릭터를 복제하기로 결정한 것이 아니며, 이 문서는 시장 검증을 완료했다는 주장도 아니다.

## 아직 결정하지 않은 것

HP 승패, 체크 중 다른 수 허용, 융합 결과/포획 후 처리, 손패의 런 영구 편입, 출전 슬롯, 손실·패배·저장 정책, 런 길이, 영구 성장, 아트 스타일, 수익화는 미정이다. AI가 빈칸을 임시로 메우면 PR에 가정과 되돌리는 방법을 명시하고 확정 합의로 서술하지 않는다.

실행 순서는 [로드맵](roadmap.md), 실험 관찰 방식은 [실험 헌장](experiment-charter.md), 실제 완료 상태는 [인계](handoff.md)를 참고한다.
